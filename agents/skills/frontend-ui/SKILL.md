name: frontend-ui
description: Invoke when working on frontend UI or UX design.
---

Design work belongs to `pi-ui`, which carries the design skills (accessibility, layout, typography, color, polish, copy, motion, interface reviews) and real-site references this session lacks.

- Hand it any task that designs, builds, restyles, animates or reviews an interface, as the Specialists section of your instructions describes. Name the screens or components and what done looks like, and check its screenshots and diff before you report.
- Do code-level UI work yourself: state, data flow, a prop or a bug fix with no design decision.
- When `pi-ui` is not on PATH, work from the project's existing tokens and components, and say in your report that the design pass was skipped.
